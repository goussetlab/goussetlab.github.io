# Gousset Lab website

Lab website for Karine Gousset, Ph.D., California State University, Fresno.

Website: https://goussetlab.github.io/

## Pages

- `Welcome.html`: home
- `About_Me.html`: principal investigator
- `Lab_Members.html`: lab members
- `Publications.html`: publications
- `TNT_Movies.html`: research videos
- `Links.html`: resources

This is a static HTML site migrated from the current Dreamweaver site. Referenced images and PDFs are included at the repository root, with their original folder name prefixed to each filename to keep names unique. Page references have been updated to match. `index.html` opens the current home page; `.nojekyll` tells GitHub Pages to serve the files directly.

## Updating the website

Edit the HTML and assets in this repository, then commit changes to `main`. GitHub Pages publishes `main` from the repository root. You can use GitHub's web editor or clone this repository and edit the local copy in Dreamweaver.

The migration preserves the six current pages and their referenced assets. Older unlinked iWeb archives, the separate biology building map, and Dreamweaver metadata are not part of this site.
